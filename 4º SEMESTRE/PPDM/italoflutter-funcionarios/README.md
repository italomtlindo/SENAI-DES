# 👨‍💼 Flutter Funcionários

![Flutter](https://img.shields.io/badge/Flutter-3.0-blue?logo=flutter)
![Dart](https://img.shields.io/badge/Dart-2.0-0175C2?logo=dart)
![Status](https://img.shields.io/badge/Status-Concluído-brightgreen)

Aplicativo Flutter que exibe uma lista de funcionários carregados via JSON local, com navegação entre perfis, Splash Screen animada e interface personalizada.

---

## 🚀 Demonstração

> App desenvolvido como atividade acadêmica para praticar Flutter, animações e manipulação de JSON.

---

## ✨ Funcionalidades

- 📄 Leitura de JSON local (`assets/mockup/funcionarios.json`)
- 🧑‍💼 Lista de funcionários com informações completas
- 🖼️ Avatares personalizados via URL
- 🔽 Dropdown para seleção de funcionários
- 🔄 Navegação entre perfis (um a um)
- 🎬 Splash Screen animada (fade/scale/move)
- 🎨 Tema personalizado (Theme + Palette)
- 📱 UI organizada com Containers e Material Design
